# SyntaxWear E-commerce

Este é um projeto de front-end para um site de e-commerce de calçados chamado SyntaxWear. O site foi projetado para ser moderno, responsivo e visualmente atraente, com foco na apresentação de produtos de calçados.

## 📜 Descrição

SyntaxWear é uma loja online fictícia especializada em tênis e sneakers. O layout da página inicial foi construído para destacar os produtos e categorias, proporcionando uma experiência de usuário limpa e intuitiva.

## ✨ Features

- **Design Responsivo:** Layout adaptável para visualização em desktops, tablets e dispositivos móveis.
- **Página Inicial Atrativa:** Inclui uma seção "hero" com chamada para ação (CTA), categorias de produtos e uma grade de produtos em destaque.
- **Navegação Intuitiva:** Menus claros no cabeçalho e rodapé para fácil acesso às seções do site.
- **Componentes Modulares:** O CSS é estruturado em componentes reutilizáveis, facilitando a manutenção e expansão.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Para a estrutura semântica do conteúdo.
- **CSS3:** Para estilização, utilizando variáveis, layout flexbox e grid. A metodologia BEM (Block, Element, Modifier) pode ser inferida pela estrutura de classes.

## 📂 Estrutura do Projeto

O projeto está organizado da seguinte forma:

```
ecommerce-syntaxwear/
├── index.html               # Arquivo principal da página inicial
├── README.md                # Este arquivo
└── assets/
    ├── css/
    │   ├── base.css             # Estilos base (cores, fontes)
    │   ├── reset.css            # Reset de estilos do navegador
    │   ├── variables.css        # Variáveis CSS globais
    │   └── components/          # Estilos para componentes específicos
    │       ├── footer.css
    │       ├── header.css
    │       ├── hero.css
    │       ├── product-category.css
    │       └── product-grid.css
    ├── icons/                   # Ícones (atualmente vazio)
    └── images/
        ├── banner/              # Imagens do banner principal
        ├── favicons/            # Favicons do site
        ├── Icons/               # Ícones de redes sociais e UI
        ├── logo/                # Logo do site
        └── products/            # Imagens de produtos
```

## 🏃 Como Executar

Como este é um projeto estático de HTML e CSS, você pode simplesmente abrir o arquivo `index.html` em seu navegador de preferência.

1.  Clone este repositório:
    ```bash
    git clone <URL_DO_REPOSITORIO>
    ```
2.  Navegue até o diretório do projeto:
    ```bash
    cd ecommerce-syntaxwear
    ```
3.  Abra o arquivo `index.html` no seu navegador.

Nenhuma dependência ou build step é necessário.
